## English 🇬🇧

A small and lightweight PowerShell script designed to automatically generate music playlists from your local audio files. It includes separate versions for English and German users, along with convenient batch (`.bat`) files for quick execution.

### Features
* **Automated Generation:** Scan your directories and create music playlists effortlessly.
* **Easy Execution:** Run the script directly or use the provided `.bat` wrappers without manually opening PowerShell.
* **Bilingual Support:** Full independent files for both English and German speakers.

### File Structure
* `playlist-generator-(En).ps1` — The core PowerShell script (English version).
* `playlist-generator-(En).bat` — Batch file launcher for the English script.
* `playlist-generator-(De).ps1` — The core PowerShell script (German version).
* `playlist-generator-(De).bat` — Batch file launcher for the German script.

### How to Use
1. **Clone or Download** this repository to your local machine.
2. Place the script files into the directory containing your music, or configure the paths inside the script.
3. Double-click the `.bat` file (e.g., `playlist-generator-(En).bat`) to run the generator instantly.

## Deutsch 🇩🇪

Ein kleines und leichtgewichtiges PowerShell-Skript zur automatischen Erstellung von Musik-Playlists aus Ihren lokalen Audiodateien. Es enthält separate Versionen für englisch- und deutschsprachige Benutzer sowie praktische Batch-Dateien (`.bat`) zur schnellen Ausführung.

### Funktionen
* **Automatische Erstellung:** Durchsucht Ihre Verzeichnisse und erstellt mühelos Musik-Playlists.
* **Einfache Ausführung:** Starten Sie das Skript direkt oder nutzen Sie die bereitgestellten `.bat`-Dateien, ohne PowerShell manuell öffnen zu müssen.
* **Zweisprachige Unterstützung:** Eigenständige Dateien sowohl für Deutsch als auch für Englisch.

### Dateistruktur
* `playlist-generator-(De).ps1` — Das Haupt-PowerShell-Skript (Deutsche Version).
* `playlist-generator-(De).bat` — Batch-Datei zum Starten des deutschen Skripts.
* `playlist-generator-(En).ps1` — Das Haupt-PowerShell-Skript (Englische Version).
* `playlist-generator-(En).bat` — Batch-Datei zum Starten des englischen Skripts.

### Verwendung
1. **Klonen oder laden** Sie dieses Repository auf Ihren lokalen Computer herunter.
2. Platzieren Sie die Skriptdateien in dem Ordner, der Ihre Musik enthält, oder passen Sie die Pfade innerhalb des Skripts an.
3. Klicken Sie doppelt auf die entsprechende `.bat`-Datei (z. B. `playlist-generator-(De).bat`), um den Generator direkt zu starten.
